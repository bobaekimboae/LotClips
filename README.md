# LotClips

LotClips는 중고차 사진 여러 장과 차량 정보를 세로형 숏폼 MP4 영상으로 만드는 한국어 웹 앱입니다. 페이지는 LotClips 업로드 화면을 직접 확인해 구성했으며, 영상 생성은 브라우저 안에서 처리합니다. 업로드한 사진은 서버로 전송되지 않습니다.

## 사용 방법

1. `https://bobaekimboae.github.io/LotClips/`를 엽니다.
2. 차량 사진을 선택하거나 업로드 영역으로 끌어옵니다. 사진 목록 행을 드래그해 순서를 바꿀 수 있습니다.
3. 연식, 제조사, 모델, 가격, 주행거리와 특장점을 입력합니다.
4. **영상 미리보기**를 눌러 9:16 MP4를 생성하고 재생합니다.
5. **MP4 다운로드**를 눌러 저장합니다.

## 로컬 실행

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:5173/LotClips/`를 엽니다. 프로덕션 빌드는 `npm run build`로 생성합니다.

## 동작 및 제한

- MP4 인코딩은 Mediabunny와 브라우저 WebCodecs를 사용합니다. WebCodecs가 없는 브라우저에서는 MediaRecorder로 WebM 파일을 만듭니다. 최신 Chrome 또는 Edge를 권장합니다.
- 사진 한 장을 약 2.8초간 보여 주며, 느린 확대 효과와 차량 정보 오버레이를 적용합니다.
- 사진 파일은 브라우저 메모리에서만 처리됩니다. 앱은 계정, 서버 저장소, 결제, 실제 매물 사이트 연결을 제공하지 않습니다.
- 상단의 무료 체험 잔여 수와 업그레이드/추가 구매는 원본 업로드 화면을 본떠 배치한 UI입니다. 이 앱의 실제 크레딧이나 결제와 연결되지 않습니다.
- 매물 링크 자동 가져오기는 정적 GitHub Pages에서 원본 사이트의 CORS/API 접근 권한이 없어 동작하지 않습니다. 직접 사진을 올리고 정보를 입력해 주세요.
- HEIC 디코딩은 운영체제/브라우저 지원에 따라 다릅니다. 지원되지 않으면 JPG 또는 PNG로 변환해 업로드하세요.

## 기술

React, Vite, Mediabunny, Lucide. GitHub Pages 배포는 `.github/workflows/pages.yml`이 수행합니다.

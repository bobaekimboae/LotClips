# LotClips

LotClips는 중고차 사진과 영상 클립을 연결해 세로형 숏폼을 만드는 한국어 웹 앱입니다. 업로드 화면의 어두운 작업 공간, 왼쪽 메뉴, 매물 URL 입력, 클립 목록, 차량 정보, 특장점 선택 및 영상 미리보기를 구현했습니다.

## 사용 방법

1. [LotClips 열기](https://bobaekimboae.github.io/LotClips/)
2. 사진 또는 동영상 클립을 선택하거나 업로드 영역으로 끌어옵니다. 목록을 끌어 순서를 바꾸거나 항목을 제거할 수 있습니다.
3. 연식, 제조사, 모델, 가격을 입력합니다. 주행거리와 특장점은 선택 사항입니다.
4. **영상 미리보기**를 눌러 세로형 영상을 만들고 재생을 확인합니다.
5. **MP4 다운로드** 또는 브라우저가 지원하는 경우 **WebM 다운로드**를 눌러 저장합니다.

## 로컬 실행

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:5173/LotClips/`를 엽니다. 프로덕션 빌드는 `npm run build`로 생성합니다.

## 데이터 처리와 제한

- 사진·영상 클립은 브라우저 메모리에서 처리하며 외부 서버로 업로드하지 않습니다.
- MP4 인코딩은 Mediabunny와 브라우저 WebCodecs를 사용합니다. WebCodecs가 없는 브라우저에서는 MediaRecorder로 WebM을 생성합니다. 최신 Chrome 또는 Edge를 권장합니다.
- 사진은 장당 약 2.8초, 영상 클립은 최대 6초 분량을 영상에 포함합니다. 사진에 확대 효과와 차량 정보 오버레이를 적용합니다.
- 매물 URL 자동 가져오기는 서버 프록시가 없어 현재 동작하지 않습니다. 차량 정보를 직접 입력하고 사진을 올려 주세요.
- 로그인, 계정, 결제, 크레딧 표시는 원본 화면을 참고한 UI이며 실제 계정·과금 서비스와 연결되지 않습니다.
- HEIC 인식은 브라우저 지원에 따라 다를 수 있습니다. 문제가 있으면 JPG 또는 PNG로 변환해 업로드하세요.
